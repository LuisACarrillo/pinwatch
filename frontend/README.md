# PinWatch frontend

Aplicación React creada con Vite. Forma parte del monorepo y se instala con pnpm desde la raíz del repositorio.

```powershell
pnpm install
pnpm dev
```

- `src/components`: componentes de interfaz.
- `src/services`: cliente HTTP de la API (`VITE_API_URL`, por defecto `http://localhost:8000`).

La guía del monorepo está en el `README.md` de la raíz.
